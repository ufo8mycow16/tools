# WoW Model Viewer 1.1 (source archive)

Glen's copy of WoW Model Viewer 1.1, full source tree (Windows program: views and exports WoW models,
textures and buildings from a local install; OBJ/PNG/BLP export). Kept here as split parts.

Rebuild the archive:
    cat wowmodelviewer-1.1.tar.gz.part* > wowmodelviewer-1.1.tar.gz
    sha256sum -c SHA256SUMS
    tar -xzf wowmodelviewer-1.1.tar.gz
